# Borgaro Torinese 城市分析工作指南

**负责主题：** Paths & Edges（路径与边界）＋ Urban Morphology（城市形态）  
**用途：** 供本次小组 review 讨论的阶段性工作材料，不是最终 A1 展板。

## 1. 本次 review 要求

老师希望每组带来正在发展的 territorial analysis 和 urban analysis 材料，形式可以是手绘、描图纸叠绘、电脑制图、草图、分析图或示意图。材料尚未完成也可以；重点是能够和教学团队讨论。

- 至少准备 **3 张地图**；没有规定必须做成 A1，也欢迎其他格式。
- 图纸可以是工作稿，标出已确认的发现、暂时判断和还需要核实的问题。
- 不要只罗列道路、建筑或绿地；要解释它们之间的关系，以及对场地可达性、空间连续性和未来设计可能意味着什么。
- 最终阶段再整理为 A1 展板。本次 review 先让分析思路和关键发现可读、可讨论。

## 2. 我的分析目标

### A. Paths & Edges｜路径与边界

分析铁路、高速公路、主次干道和自行车道构成的交通网络，同时判断它们何处连接城市、何处形成阻隔。

需要回答：

1. 主要交通线路怎样连接 Borgaro、周边城镇和都灵？
2. 铁路、高速公路、快速路或宽阔道路是否切分街区、阻碍步行/骑行或限制场地出入口？
3. 哪里可以穿越这些边界？穿越点之间的距离是否过大？是否有桥梁、地下通道、平交口或断头路？
4. 自行车路线是否连续，能否连接住宅区、公共空间、公共交通和重要设施？
5. 场地与周边道路、步行和自行车网络之间有哪些明确的入口或缺口？

**工作时可用的概念：** 连通性、可达性、渗透性、网络层级、断点、边缘、穿越点、道路界面。把“路径”理解为交通移动的线路，把“边界”理解为阻挡、分隔或塑造城市边缘的线性要素；同一条铁路或道路可能同时承担两种作用。

### B. Urban Morphology｜城市形态

分析建筑布局、街区形状与尺度、建成密度，以及建筑和开放空间的关系。

需要回答：

1. 建筑是沿街连续排列、围合街区、独立散置，还是以大型厂房/设施为主？
2. 街区大小和形状是否规则？街道网络是否细密、连贯，还是由大街区和少数道路组成？
3. 建筑覆盖了多少地面？开放空间是公共、半公共还是私有？是否被道路或围墙分隔？
4. 不同片区的形态和密度有什么变化？例如中心/外围、住宅/工业、旧区/新区之间的差异。
5. 哪些开放空间能连接成连续网络，哪些只是孤立空地或建筑间隙？
6. 这些形态特征会怎样影响步行尺度、街道活力、公共空间可达性和未来连接机会？

## 3. 建议准备的 4 张工作图

至少完成前三张；第四张可作为综合图。如果时间有限，先画范围清楚、图例明确的手绘分析图也可以。

### 图 1｜区域交通路径与网络层级

**范围：** Borgaro 与邻近城镇、都灵方向的区域联系。建议从 territorial 尺度开始，讲义建议约 **1:10,000、1:15,000 或 1:20,000**；也可用能完整显示区域联系的比例。

**画出：** 铁路、高速公路/环路、主干道、次干道、自行车道；标注主要方向、重要交叉点、交通枢纽和场地位置。

**分析：** 哪些线路提供区域级连接，哪些服务于本地出行？不同网络之间在哪里换乘或衔接？骑行网络有没有断点？从场地到都灵及邻近城镇的路线是否直接？

**建议表达：** 按道路/线路层级区分线宽和颜色；用箭头表示主要流向；用虚线或醒目符号标出自行车道中断、缺少连接的位置。

### 图 2｜边界、障碍与穿越机会

**范围：** 场地及其周边街区。建议 urban 尺度约 **1:2,500 或 1:1,000**，按底图可读性调整。

**画出：** 铁路、高等级道路、围墙或大型封闭地块等线性边界；桥梁、地下通道、平交道口、路口和步行/骑行穿越点；断头路、封闭边缘和场地出入口。

**分析：** 哪些边界最难穿越？两处有效穿越点之间相隔多远？场地哪一侧最容易到达、哪一侧被切断？是否存在可补足的步行或骑行连接？

**建议表达：** 用粗实线表示强阻隔，用较细线表示可穿越但不连续的边界；用箭头或节点标出穿越点；用阴影/色块标出被隔离的区域。距离和判断需在底图上量测或现场核对，不要凭视觉估算后写成确定数据。

### 图 3｜建筑肌理、街区与建成/开放空间

**范围：** 与图 2 尽量一致，便于叠加比较。

**画出：** 建筑轮廓、街区边界、主要开放空间、道路和明显的大型地块。按形态给建筑或片区分类，例如连续沿街、围合街区、独立建筑、工业/仓储大体量、低密度住宅等；分类要以实际观察为准。

**分析：** 比较街区尺度、建筑排列、空间围合程度和开放空间连续性。指出建成密集区、大型开放地块、边缘地带、形态突变处，以及建筑或地块如何影响街道连通。

**建议表达：** 建筑用深色填充、开放空间用浅色或绿色、道路留白；用少量纹理/符号区分形态类型。先确保建成与开放空间一眼可辨，再增加分类。

### 图 4｜综合诊断：连接、形态与设计关注点

把图 2 和图 3 的发现综合到一张图上，标出：

- 主要路径和可改善的连接；
- 关键阻隔及其穿越机会；
- 形态较连续、较破碎或尺度突变的片区；
- 有潜力形成公共空间/步行骑行网络的开放空间；
- 需要在后续设计阶段回应的 3–5 个问题或机会。

每个标注尽量采用“观察 → 影响 → 设计问题”的写法。例如：**铁路穿越点少 → 两侧街区联系受限 → 是否可以加强某处步行/骑行穿越？** 具体结论需由你的地图证据支持。

## 4. 可量化的初步指标

本次不必把所有指标都算完。选择能支撑地图发现的少数指标，并注明数据范围和计算方法。没有数据时可以先标注“待测”，不要编造数值。

### 路径与边界

- 各级道路、铁路、自行车道的空间分布和连续性；
- 指定范围内可穿越铁路/高等级道路的点位及相邻穿越点间距；
- 场地到最近道路、自行车线路或重要节点的网络距离（直线距离不能代替实际路径距离）；
- 场地边界上可进入的位置，以及与周边街网相接的位置。

### 城市形态

- 街区面积或街区尺度分布；
- 建筑覆盖率：建筑占地面积 ÷ 统计范围面积；
- 建成空间与开放空间的大致比例；
- 不同形态片区的建筑排列、街道密度或开放空间连续性对比。

若用 QGIS 计算，请在图注中说明统计范围、图层来源、筛选规则和单位。建筑覆盖率不等同于法定容积率，也不能单独代表人口密度。

## 5. 可用资料与工作方法

项目已提供 Borgaro 区域的 QGIS/BDTRE 数据。方法说明列出的相关主题包括：行政边界、地名、植被、地形、水系、建筑与人工设施、道路/交通等。可先打开现有 QGIS 项目检查图层，再根据需要筛选和叠加。BDTRE 中的图层不一定都有要素；空图层不代表该要素现实中不存在。

- **交通分析：** 使用道路/交通图层辨认道路层级、自行车道和铁路；结合底图或现场观察核查通行与穿越点。
- **形态分析：** 从建筑轮廓和道路生成图面；手动补充街区边界、开放空间类型及难以从数据识别的围墙/封闭界面。
- **核对现场：** 讲义强调区域与场地认识。对穿越是否可用、道路界面和自行车道连续性等关键判断，尽可能通过 site visit、照片或可靠资料核实。
- **工作稿表达：** 手绘叠图或电脑制图均可。地图至少注明标题、北箭头/方向、比例或范围、图例、底图/数据来源和日期；暂定判断标为“初步观察”。

**项目内相关资料：**

- `Territorial data/BDTRE_DATABASE_GEOTOPOGRAFICO_2025-LIMI_COMUNI_10_GAIMSDWL-001272-EPSG32632-GPKG.qgs`：已加载并组织图层的 QGIS 项目。
- `Territorial data/NOTA_METODOLOGICA.txt`：BDTRE 数据结构和图层主题说明。
- `Pdf to use as a base/`：提供不同范围/比例的 Borgaro 底图 PDF，可用于叠图和确定图幅。

## 7. Review 时可展示的工作状态

建议每张图旁边附 2–3 条简短说明：

1. **我观察到什么**（地图上的空间事实）；
2. **这可能意味着什么**（可达性、阻隔、街区形态或开放空间的影响）；
3. **我还需要核实什么**（缺失数据、现场观察或下一步分析）。

这样即使地图仍是草图，也能清楚地作为小组讨论材料。
